## 🚀 Key Highlights & Features

### 1. 📘 Comprehensive B.Tech Tutorials
Structured, beginner-friendly tutorials covering the entire undergraduate programming syllabus:
- **C Programming**: Pointers, Dynamic Memory Allocation (`malloc`, `free`), Structs, File I/O, Matrix Manipulations.
- **Python**: Dynamic typing, List Comprehensions, OOP (Inheritance, Polymorphism), Exception Handling, File I/O.
- **Java**: JVM internals, Bytecode, Encapsulation, Abstract Classes & Interfaces, Collections Framework (`ArrayList`, `HashMap`).
- **HTML5**: Semantic tags, Forms & Validation, Accessibility, Responsive layout structure.
- **CSS3**: Box Model, Flexbox, Grid, CSS Variables, Animations, Mobile Media Queries.
- **JavaScript (ES6+)**: Scope & Closures, Promises, Async/Await, DOM Manipulation, Array Methods.

### 2. ⚡ Coding Practice Arena with Real Compilers
- Real compilation & execution:
  - **C**: GCC 14.1.0 (via Judge0 CE public engine)
  - **Java**: OpenJDK 17.0.6 (via Judge0 CE public engine)
  - **Python**: Python 3.12 (via Judge0 engine)
  - **JavaScript**: Sandboxed in-browser runtime with console output capture
- **Zero Fake Emulation**: We never pretend to run C or Java code; the execution is real with genuine compiler diagnostics, memory usage, and execution time.
- Problem explorer with difficulty filters (Easy, Medium, Hard, B.Tech Lab Level).
- Three-tier hints system and complete sample solutions with Big-O complexity analysis.
- Custom STDIN input support and automated test-case evaluation.

### 3. 🎯 Interactive Quizzes & Learning-Gap Detection
- Multi-topic multiple choice quizzes for exam prep and GATE / campus placement tests.
- **Learning-Gap Engine**: Analyzes your quiz accuracy and coding attempts. When accuracy drops below 60% in any topic (e.g., *C Pointers* or *Java Abstraction*), it flags a critical gap and generates a targeted remedial roadmap!

### 4. 🧭 4-Year B.Tech Semester Roadmap
- Interactive semester-by-semester guide from Semester 1 through Semester 8.
- Maps engineering fundamentals, algorithms, system design, and placement interview preparation.

### 5. ⏳ B.Tech Study Toolkit
- **Pomodoro Study Timer**: 25m Focus, 5m Short Break, 15m Long Break with synthesized Web Audio chimes and study logs.
- **3D Flashcards**: Flip cards for quick revision of syntax, Big-O complexities, and core concepts.
- **Personal Notes**: Clean markdown-friendly notepad with tags, search, and JSON/TXT export.
- **Streak & XP Tracker**: Motivates daily coding practice with milestone achievement badges.

### 6. 🔒 Supabase PostgreSQL Cloud Sync & Demo Mode
- **Zero Config Demo Mode**: Works immediately in your browser via `localStorage`.
- **Optional Supabase Cloud Backend**: Connect your free Supabase project to unlock cloud sync, multi-device access, and PostgreSQL persistence with Row Level Security (RLS).
- **Zero Secret Key Exposure**: Strictly uses client `anon` public key; credentials never hardcoded.

### 7. 🤖 Optional AI Tutor
- Connect an optional free Google Gemini API key to ask questions, explain code snippets, or diagnose errors.
- Built-in offline intelligent tutor provides guidance even without an API key!
